# Documentação do protótipo

Esta pasta transforma o comportamento navegável em requisitos implementáveis. O código permanece na raiz de `Prototipo/` para continuar simples de abrir e apresentar.

- [`REGRAS_DE_NEGOCIO.md`](REGRAS_DE_NEGOCIO.md): catálogo das regras demonstradas.
- [`PRECOCIFICACAO.md`](PRECOCIFICACAO.md): modelo simples de precificação com custo primário, encargos fixos e margem sobre venda.
- [`CONTRATO_FICHA_TECNICA.md`](CONTRATO_FICHA_TECNICA.md): requisito da ficha técnica.
- [`CONTRATO_ETIQUETAS.md`](CONTRATO_ETIQUETAS.md): requisito demonstrado para modelos e etiquetas vinculadas à OP.
- [`MATRIZ_PROTOTIPO_FLUTTER.md`](MATRIZ_PROTOTIPO_FLUTTER.md): comparação e backlog técnico.
- [`COMO_REGISTRAR_MUDANCAS.md`](COMO_REGISTRAR_MUDANCAS.md): rotina após cada conversa.

Os documentos antigos foram mantidos para preservar histórico e links. Novas regras recebem um ID estável neste catálogo.
